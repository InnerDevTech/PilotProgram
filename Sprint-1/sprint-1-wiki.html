Expected outcome

By the end of Sprint 1 the projector screen should be driven entirely by real hardware — no keyboard. Four buttons on pins 2 to 5 and a knob on A0 feed the Arduino Uno, the bridge passes those presses to the page, and the page responds: button 1 cycles Home, Timer and Stopwatch; the knob picks 1 to 60 minutes; buttons 2 and 3 start, pause and reset; button 4 speaks the time; the timer beeps at zero.

The buttons should be mounted so they do not shift when pressed, and each press should count exactly once — debounce handled in the sketch rather than ignored. A classmate who has never seen the project should be able to set a timer using only the "how to use" card.

Demo checklist

  • Clock shows on the projector.
  • Button 1 cycles Home, Timer, Stopwatch.
  • Knob sets the minutes, 1 to 60.
  • Button 2 starts and pauses. Button 3 resets.
  • Button 4 says the time.
  • The timer beeps at zero.

Definition of done

All checklist items pass three times in a row, with no code errors in the bridge window.

Risk to watch: the Serial Monitor is open — it blocks the bridge and you get "Could not use COM3". Close it before starting the bridge, and put that on the setup card.
