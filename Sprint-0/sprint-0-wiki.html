Expected outcome

By the end of Sprint 0 the project should run on every team laptop with no hardware attached. Both test suites pass — 14 Python tests and 12 physics tests — and python bridge/jarvis_bridge.py --no-serial opens the projector page, where keys 1 to 4 move between the Home, Timer and Stopwatch screens and the timer counts down.

Away from the keyboard, the team should be set up to work: roles assigned and written on the board, every person able to explain one file in the codebase, the desk measured with all 16 IR beam positions drawn, parts ordered against the budget, and the board loaded with Sprint 1 cards in TO DO.

Nothing physical is built this sprint. No buttons, no sensors, no camera — that starts in Sprint 1, and only if this demo passes.

Definition of done

  • Tests pass on every laptop.
  • The team can run the button page.
  • Parts are ordered.
  • The board is ready.
Rule for the team: if this sprint's demo does not pass, do not start Sprint 1. Fix the gap first.
