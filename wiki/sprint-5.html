Expected outcome

By the end of Sprint 5 nothing new should have been added — the sprint is about making what exists trustworthy. The top three bugs are fixed, each with a test so they cannot come back silently, and both test suites pass.

The Build Guide should have been walked step by step on a clean folder and corrected wherever it was wrong or unclear, with the README and wiki brought in line with the code. The wiring should be tidy and labelled at both ends of every wire, and the safety section should cover low voltage, the IR warning and privacy.

The real proof is a classmate who did not build the desk starting it from the docs alone, and the full demo running three times in a row without a crash. If someone else can run it, it is finished; if only you can run it, it is not.

Demo checklist

  • A new person can build and start the desk using only the docs.
  • All automated tests pass (python -m unittest discover -s tests -v and node tests/test_physics.js).
  • The full demo runs 3 times in a row without a crash.
  • Every wire is labelled.

Definition of done

The docs have been tested by someone who did not write them.
